# climate-resources
Climate Advocate Resource Database

Welcome to Team CARD (Climate Advocates Resource Database). The aim of this group is to bridge the gap between the scientists and policy makers. We are seeking papers that are linked to climate change from any discipline in any location throughout the world. To ensure that data is available and accessible for EVERYONE, please describe your papers in lay-mans terms. We want science to be understood by everyone. When we understand science, lasting change can be made!
